# 個人・チーム固有の既定（雛形）

このファイルは `local/preferences.md` としてコピーして使う。**`local/` は .gitignore 済み。**

リポジトリ本体には「他プロジェクト・他の人にも普遍的に使えるもの」だけを置く。
流儀で変わるもの（コミット規約・PR の出し方・進め方）はここへ書く。

**個人設定はプロジェクト規約に優先しない。** ここに書いたことと導入先の規約が食い違う場合は、
導入先の規約に従う。判断がつかない場合は止めて確認する。

`~/.claude/CLAUDE.md` から import して効かせる。配置先を決め打ちせず、
[README の導入手順](../README.md#導入) と同様にリポジトリ内で次を実行し、
表示された行を `~/.claude/CLAUDE.md` に記入する。

```bash
./install.sh     # 足す import 行を表示する
```

**自分でパスを組み立てない。** `git rev-parse --show-toplevel` は非 git のコピーで
空文字になり、`@/claude/principles.md` という**壊れた行を終了コード 0 で出す**。

1行目はリポジトリ本体の原則、2行目は `local/preferences.md` を作成した場合の個人設定用。

## 例

- コミットメッセージ: Conventional Commits
- PR: Draft で作成する
- PR は1本ずつ。マージを確認してから次へ進む
- memory を書くときは本文に出来事の日付を必ず入れる（時系列の計測に要る）

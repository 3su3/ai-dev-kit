# Public-ready 原則

`3su3/ai-dev-kit` は Private 運用中も、公開可能と判断できる情報だけを扱います。この原則は、このリポジトリへ追加・変更する文書、コード、設定、例、画像、ログ、リンク先の説明などに適用します。ハーネスを導入した別のプロジェクトの公開方針を定めるものではありません。

## 持ち込まない情報

- 仕事・顧客・他リポジトリの機密情報や、その内容を推測できる具体的な情報
- パスワード、トークン、秘密鍵などの秘密情報。例や検証結果にも実際の値を使わない
- 出所、利用許諾、公開する権利が確認できない文章・コード・画像などの素材

Private であることは、これらを持ち込む理由にはなりません。抽象化した説明や架空の値を使う場合も、元の情報を復元・推測できないか確認してください。

## 判断できない場合

持ち込み前に作業を止め、安全な概要だけを添えて Human に確認してください。判断待ちの素材をファイル、Issue、PR、コミット、エージェントの配布先へ載せないでください。質問に秘密情報の値や権利不明の内容を貼らないでください。

既存ファイルや履歴で疑義を見つけた場合も、公開可能と扱わず Human に報告してください。既存情報の対処は別の承認された作業として扱います。

## Public 化

この原則に沿って作業したことは、リポジトリや履歴の Public 化を承認・保証しません。実際の Public 化には、対象と既存履歴を確認したうえで Human の別途明示承認が必要です。

## 検証の順序

**実機（検証環境）での確認は、セルフレビューと AI レビューが通ってから行う。**
レビューで設計が変わると、先に取った実機の結果は捨てることになる。

この計画における順序を書いてください。既定から外れる場合は理由も書いてください。

| | いつ | 例 |
|---|---|---|
| 1 | 実装と同時 | テスト・Lint・静的解析 |
| 2 | 実装の後 | セルフレビュー |
| 3 | 2 の後 | AI レビュー・人のレビュー |
| 4 | **3 が通ってから** | 検証環境へ反映しての実機確認 |

**例外: 実装より先に実機で確かめる必要がある場合。** 前提が成り立つかで方針が変わるときは、
その確認を Phase 0 として実装の前に置き、**通過条件**（何が観測できたら進むか）を書いてください。
